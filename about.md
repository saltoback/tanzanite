# Tanzanite

Mod menu bleu-violet tanzanite pour Geometry Dash.

- **Noclip** : traverser les obstacles
- **Speedhack** : accélérer ou ralentir le jeu
- **Safe mode** : aucune progression enregistrée
- **Pourcentage précis** : 2 décimales

Ouvre le menu avec le bouton **Tanzanite** du menu principal ou du menu pause.
